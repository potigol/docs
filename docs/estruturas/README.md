# Decisão e Repetições

- As [estruturas de decisão](decisao/README.md) são aquelas que permitem alternativas ([`se`](decisao/se.md) e [`escolha`](decisao/escolha.md)).
- As [estruturas de repetição](repeticao/README.md) são aquelas que permitem executar repetidas vezes um trecho de código ([`para`](repeticao/para.md) e [`enquanto`](repeticao/enquanto.md)).
